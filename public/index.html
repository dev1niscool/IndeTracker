Install Inde

Add the tracker to your home screen. Downloaded news is available offline.

iPhone or iPad

In Safari, tap Share, then Add to Home Screen.

Android

In Chrome, open the menu and tap Install app or Add to Home screen.

Desktop

Use Chrome or Edge’s install icon in the address bar when available.
